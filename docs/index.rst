pymdtools documentation
=======================

Work with Markdown through small text helpers or a complete document workflow:
assemble reusable sections, edit links, generate HTML and PDF, and translate
visible text. Start with :doc:`getting_started`, then choose a task in
:doc:`workflows`. The API pages describe the installed version shown in this site.

Core features need Python and the package's core dependencies. PDF rendering
additionally needs the ``pdf`` extra and Chromium; translation uses the network
unless a local transport is supplied.

Licenses and attribution
========================

The original code, bundled layouts and installed dependencies have separate
notices. These pages include the repository inventories directly, so the website
and distributed files describe the same reviewed state.

.. toctree::
   :maxdepth: 1

   project_license
   LICENSES-3rd-party
   LICENSES-dependencies

HTML exports include per-layout ``LICENSES.txt`` files in their asset trees.
Keep those notices when sharing generated pages. The bundled-resource inventory
records unresolved historical theme permissions rather than assigning the
project's MIT license to those works. The dependency inventory is a dated review;
its listed versions are not additional dependency constraints.
